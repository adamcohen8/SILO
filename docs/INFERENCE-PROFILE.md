# First inference evaluation profile

The data-only [candidate profile](../profiles/nemotron-30b-4090-candidate.json) records exact source revisions and publisher metadata. It does not execute commands, select the production architecture, authorize licenses, or claim GPU compatibility. No weights have been downloaded.

The starting experiment is Nemotron 3 Nano 30B-A3B with the Unsloth IQ4_XS GGUF (18,168,955,680 bytes, about 16.9 GiB) and a pinned llama.cpp CUDA source revision. This is a third-party quantization. Its size leaves more nominal room within 24 GiB than that repository's Q4_K_M asset (24,574,373,664 bytes, about 22.9 GiB); runtime buffers, context/state, display use, and other workloads still need measurement. This comparison is an inference from publisher sizes, not proof that IQ4_XS fits or that its quality is acceptable. See [publisher files](https://huggingface.co/unsloth/Nemotron-3-Nano-30B-A3B-GGUF/tree/9ad8b366c308f931b2a96b9306f0b41aef9cd405).

Use one concurrent request and an initial 8,192-token context / 1,024-token generation limit. These are conservative experiment settings, not model maxima or quality guarantees. Start with reasoning disabled only after verifying that the pinned runtime/template honors it. The proposed tool-call sampling settings follow [NVIDIA's model guidance](https://huggingface.co/nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B-BF16/tree/bf77c3174f68ad409e1c2aa60daeb46e32d1c606). Reasoning/token-budget truncation must fail rather than accept an incomplete tool result.

Evaluate native Windows CUDA first to avoid introducing WSL-wide settings before inventory. Compatibility of GPU inference with the proposed containment remains unknown. A WSL alternative needs a separate tested profile and the same acceptance gates. No automatic CPU/cloud/runtime fallback is allowed. See [llama.cpp tool calling](https://github.com/ggml-org/llama.cpp/blob/50569eb87df530daff11afda229ceb9ab8e6cae8/docs/function-calling.md).

Before acquiring a complete bundle, reconcile the upstream Nemotron license with the quantizer's differently named license declaration, choose/build a Windows runtime artifact, and pin every CUDA/runtime DLL, Python wheel, tokenizer/template, and license text. Source commit IDs and publisher LFS hashes are useful provenance; they are not signatures or local payload verification. Unresolved binary/dependency fields are deliberately null. The current Mac agent dependency file is not a Windows production lock.

Target measurements must record the profile/hash identities, Windows build, GPU driver, available/peak VRAM, load time, generation latency, completion/timeout/OOM behavior, and whether simultaneous host use works. Evaluate real structured tool calls through LangGraph, including unavailable folders, malicious document instructions, citations, stale sources, and reviewed new-copy saves. A small synthetic corpus cannot establish general accuracy or CUI authorization.
